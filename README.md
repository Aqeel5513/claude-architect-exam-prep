# Claude Architect Exam Prep

Study notes and preparation material for the Claude Architect certification exam.

## About

This repository collects notes, summaries, and practice material for the exam, written as plain Markdown files.

## Structure

Content will be organized by exam domain as it is added. Planned areas include:

- Claude models and model selection
- Prompt engineering
- Tool use and agents
- Model Context Protocol (MCP)
- Claude Code and the Agent SDK
- Prompt caching, context management, and cost optimization
- Evaluation, safety, and deployment patterns
